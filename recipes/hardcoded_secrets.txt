Hardcoded Secrets Prevention Guidelines:

1. Environment Variables:
   Store sensitive data (API keys, passwords) in environment variables, not in code.
   Use libraries like `python-dotenv` to load them.

2. Secret Management Services:
   Use dedicated secret management tools (e.g., AWS Secrets Manager, HashiCorp Vault).

3. Configuration Files:
   Keep secrets in separate configuration files that are excluded from version control (.gitignore).

4. Code Scanning:
   Use tools like `trufflehog` or `git-secrets` to scan your codebase for accidental commits of secrets.
